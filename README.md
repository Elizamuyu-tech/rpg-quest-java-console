# ⚔️ RPG Quest - Console Dungeon Cleaner

Jogo de aventura textual desenvolvido em **Java puro**, focado na aplicação prática dos princípios de **Programação Orientada a Objetos (POO)**, estruturas de dados e tratamento de exceções no terminal.

---

### 🎯 Objetivos Técnicos do Projeto

- **Herança e Polimorfismo:** Classe base `Personagem` com especializações (`Guerreiro`, `Mago`) substituindo comportamentos de ataque e habilidades.
- **Encapsulamento:** Proteção do estado dos personagens (pontos de vida, mana, experiência e nível).
- **Estruturas de Dados:** Uso de `List` e `Map` para controle de inventário de itens e poções.
- **Tratamento de Exceções & Input:** Validação de entradas do usuário via `Scanner` garantindo a estabilidade da aplicação.

---

### 🕹️ Como Funciona o Jogo

1. O jogador escolhe a sua classe de personagem (`Guerreiro` ou `Mago`).
2. Explora masmorras enfrentando inimigos gerados aleatoriamente.
3. Gerencia o inventário com poções de cura e restauração.
4. Acumula experiência para subir de nível e aumentar atributos.
